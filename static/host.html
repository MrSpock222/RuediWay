RuediWay am PC

Erzeuge einen Code und gib ihn am Handy oder auf der Uhr ein. Für jedes Gerät brauchst du einen eigenen Code. Alle Geräte müssen den PC erreichen können.

Verbindung wird geprüft …

Der Code gilt fünf Minuten und nur für eine Kopplung. Ein neuer Code ersetzt den alten. Beim Schließen des Handy-Browsers wechselt die Anzeige direkt, bei einer unterbrochenen Netzwerkverbindung spätestens nach 15 Sekunden auf „getrennt“. Die Uhr wird als verbunden angezeigt, solange ihre App geöffnet ist. Die Kopplung bleibt bis zu 24 Stunden gültig.
